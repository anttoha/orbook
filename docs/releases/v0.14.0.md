# ORBook v0.14.0

Seit v0.13.0 (13. November 2026).

## Neu
- Mehrere Klassen und Schulen auf einem Gerät: „Meine Klassen“ mit einer Karte pro Klasse (heute in einer Zeile, Ausfälle, nächster Test), Klasse hinzufügen per Zugangscode oder Einladungslink, „Klasse einstellen“ (Name, Farbe, Meine Kurse, Mitteilungen, Beim Start öffnen, Klasse entfernen).
- Klassen-Chip „8a ⌄“ oben: Klasse wechseln, „Alle Klassen“, „Klasse hinzufügen“. Wird der Code einer Klasse abgeschaltet, zeigt ORBook „Zugang beendet“ – die anderen Klassen laufen weiter.
- „Nebeneinander“ (Handy): ein Tag, Klassen als Spalten.
- Kurse, Notizen und Mitteilungen gelten pro Klasse.
- Sprachen: Deutsch, English, Українська (Mehr → Darstellung). Übersetzt sind bisher Menüs, Mehr, Darstellung, Wochentage und Monate.
- Admin: Klassen-Chip – die ganze Admin-Seite gilt für die gewählte Klasse. Neu „Schulen & Klassen“: Schulen hinzufügen (Schulnummer, Passwort, Server, „Verbindung testen“), Klassen mit Geräten, Codes und Tests, „Code für neue Klasse“, Klasse löschen (LÖSCHEN + Passwort, vorher Backup).
- Admin: Bei jedem neuen Code „Schule“ und „Klasse“ – eine neue Klasse entsteht mit ihrem ersten Code. Neues Recht „Klasse verwalten“ für Lehrer- und Editor-Codes: Zugangscodes und Einladungen der eigenen Klasse unter Mehr → „Klasse verwalten“.
- Admin → Einstellungen: „Klassen pro Gerät“ (Unbegrenzt, 1, 2, 3, 5, 10).

## Datenschutz
- Mehrere Klassen: Der Server speichert pro Gerät, in welchen Klassen es mit welchem Code angemeldet ist – ohne Namen. Name und Farbe der Klasse bleiben nur auf dem Gerät.
- Die gewählte Sprache bleibt nur auf dem Gerät.
