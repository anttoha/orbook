# ORBook v0.28.0

Seit v0.27.0 (21. November 2026).

## Neu
- **Lernplan zum Test (Teil 41):** im Test „Lernplan erstellen“ → `/testen/:id/lernplan`.
  - Wie viele Tage lernen (1–7, höchstens so viele, wie bis zum Test bleiben), „Auch am Wochenende“, Themen aus „Was lernen, was mitbringen“ (abwählbar) und eigene; „So lernst du“ zeigt sofort, welcher Tag welches Thema hat. Der Plan endet am Tag vor dem Test, der letzte Tag ist „Alles wiederholen“.
  - Jeder Tag ist eine Aufgabe in „Aufgaben“ und im Tag („Lernplan · Fach“); Antippen öffnet den Test. Im Test: „2 von 4 erledigt“, Fortschrittsbalken, heute hervorgehoben, am Ende „Alles gelernt!“. Auf Start im Block „Tests“ ein Balken „2/4“.
  - Test verschoben → offene Tage rutschen automatisch mit (nur bei frischer Antwort vom Server). Test gelöscht → Karte in „Aufgaben“: „Lernplan löschen“ oder „Behalten“. „Ändern“ → speichern oder „Lernplan löschen“ (mit Rückfrage).

## Datenschutz
- Unverändert: der Lernplan sind eigene Aufgaben auf dem Gerät und im verschlüsselten Sync-Block (wie bisher).

- Kein Backend-Update nötig. Android-App unverändert.
