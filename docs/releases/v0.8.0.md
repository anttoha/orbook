# ORBook v0.8.0

Seit v0.7.1 (7. November 2026).

## Neu
- **Einladen mit Link und QR:** Bei einem Gruppen-Zugangscode im Admin ⋮ → „Einladen“. Dort gibt es einen kurzen Link und einen QR-Code im ORBook-Stil, dazu „Kopieren“, „WhatsApp“ und „QR groß zeigen“ (für den Beamer, der Bildschirm bleibt an). Wer den Link öffnet, tippt auf „Beitreten“ und ist in der Klasse – das Gerät zählt zum Geräte-Limit des Codes.
- **Link steuern:** „Link aktiv“ schaltet ihn aus, „Neuen Link erzeugen“ ersetzt ihn (wer schon drin ist, bleibt angemeldet). Codes mit aktivem Link haben die Markierung LINK.
- **Klasse einladen (Schüler):** Erlaubt der Admin „Mitschüler dürfen teilen“, sehen alle den Link unter Mehr → „Klasse einladen“ (am Computer: Einstellungen).
- **Link nicht mehr gültig:** Wer einen alten Link öffnet, sieht einen Hinweis und kann sich direkt mit Code anmelden.

## Voraussetzung
Backend mit Schema 0010 (Einladungslink) – auf Prod und Demo bereits installiert.
