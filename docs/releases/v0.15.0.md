# ORBook v0.15.0

Seit v0.14.7 (13. November 2026). Teil 29d.

## Neu
- „Meine Klassen“ nach Schulen: Schulzeile über ihren Klassen, Schulseite `/klassen/schule/:id` mit „Klasse hinzufügen“; Code einer anderen Schule geht überall – die Klasse kommt zu ihrer Schule. Klassen-Wechsler nach Schulen.
- Sync-Block mit Teil `klassen`: Notizen und Kurse je Klasse, Name/Farbe/Reihenfolge; keine Zugangscodes. Schalter „Meine Klassen“ unter „Was wird synchronisiert“. Datenschutz ergänzt.
- Telegram-Bot (Backend): ein Chat für mehrere Klassen; Code/Link einer anderen Klasse fügt sie hinzu; Nachrichten mit „Schule · Klasse“ vorn; /heute, /morgen, /woche je Klasse; /einstellungen und /stop mit Klassenwahl.

## Behoben
- Endlos-Render auf „Meine Klassen“, wenn Daten einer Klasse auf dem Gerät unvollständig waren (`classPrefs`).
