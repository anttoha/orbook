# ORBook v0.14.3

Seit v0.14.2 (13. November 2026). Nur Admin.

## Neu
- Admin: Zugangscodes, Editor-Codes und Lehrer-Codes zeigen jetzt die Codes **aller Klassen** auf einmal, jeder mit einem Klassen-Schild („8a“, „07B“). Sperren, Ändern, Löschen, Einladen und „Code anzeigen“ wirken immer in der Klasse des Codes – egal, welche Klasse oben im Chip steht.
- Nach einem neuen Code für eine andere Klasse springt die Seite nicht mehr um: der Code steht einfach mit seinem Klassen-Schild in der Liste.
