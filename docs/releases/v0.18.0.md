# ORBook v0.18.0

Seit v0.17.1 (14. November 2026). Teile 31 „Android-App + Widget“, 32 „Übersetzung aller Bildschirme“ und 33 „Demo-Zugang“.

## Neu
- **Android-App** (Teil 31a): eigene Hülle (`android/`, WebView auf die Website), Seite „Android-App“ unter Mehr mit Download, QR und Anleitung, Fenster „Update ist da“. Gebaut und signiert auf dem Server (`scripts/android-build.sh`), ausgeliefert über `GET /api/public/android`.
- **Widgets** (Teil 31b): 9 Arten (Jetzt, Heute, Woche, Tests, Aufgaben …), Aktualisierung alle 30 Minuten, „Widget einstellen“ als eigene Seite mit Vorschau. Daten von `GET /api/widget`.
- **Website** (Teil 31c): Karte „Android-App“ in Mehr, Download ohne HEAD-Prüfung (Server antwortet 405), Datenschutz um App und Widgets ergänzt.
- **Übersetzung** (Teil 32): alle Texte in `t()` / `translate()`, Wörterbücher English und Українська vollständig, auch Utils, Stores, Toasts und Datenschutz. Tests prüfen, dass jeder Schlüssel übersetzt ist.
- **Demo-Zugang** (Teil 33): Demo-Codes auf dem Zugang, Editor-Code erst nach dem Login (nur Demo).

## Datenschutz
Text ergänzt: Android-App, Widget-Daten (nur auf dem Gerät), Download ohne Anmeldung. Übersetzt auf English und Українська.

## Server
Backend (Prod bereits aktuell): `GET /api/public/android`, `GET /api/public/android/apk`, `GET /api/widget`. Prod-APK wird nach dem Release mit `scripts/android-build.sh --site orbook` gebaut.
