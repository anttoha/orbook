# ORBook v0.7.0

Seit v0.6.0 (7. November 2026).

## Neu
- **Zugangscodes:** Statt eines gemeinsamen Klassenpassworts gibt es jetzt viele Zugangscodes (`ORB-A-…`) – persönlich (einer pro Schüler) oder für eine Gruppe (Eltern, Vertretung). Jeder Code hat ein Geräte-Limit (oder unbegrenzt) und ein Ablaufdatum (Standard: Schuljahresende). Der volle Code ist nur einmal beim Erstellen sichtbar.
- **Admin · Zugangscodes:** Codes erstellen, umbenennen, Limit und Gültigkeit ändern, Geräte abmelden, neu erzeugen, sperren, löschen. Gesperrte oder gelöschte Codes melden nur ihre eigenen Geräte ab.
- **Klassenpasswort** steht als Zeile „ALT“ in derselben Liste und lässt sich ausschalten, sobald alle einen Code haben (nur mit mindestens einem gültigen Code).
- **Anmelden:** ein Feld für Zugangscode oder Klassenpasswort. Klare Meldungen bei vollem Geräte-Limit und „Du wurdest abgemeldet“, wenn ein Zugang nicht mehr gilt.

## Besser
- Ein neues Klassenpasswort meldet nur noch Geräte ab, die mit dem Passwort angemeldet sind – Zugangscodes bleiben.
- Neue Codes passen in der violetten Karte in eine Zeile.

## Voraussetzung
Backend mit Datenbankschema 0009 und `/api/admin/access-codes` — auf Prod und Demo seit 7. November 2026.
