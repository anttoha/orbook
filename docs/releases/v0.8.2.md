# ORBook v0.8.2

## Besser
- **Zugangscode wieder anzeigen:** ⋮ → „Code anzeigen“ zeigt den vollen Code jederzeit (mit „Kopieren“). Der Code wird dafür verschlüsselt gespeichert; jedes Anzeigen steht im Protokoll.
