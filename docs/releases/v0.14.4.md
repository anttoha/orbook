# ORBook v0.14.4

Seit v0.14.3 (13. November 2026).

## Behoben
- Einladungslink (`/i/…`) auf einem Gerät, das schon eine Klasse hat: Die Seite leitete sofort in die App weiter, die Klasse kam nicht dazu. Jetzt prüft ORBook den Link und zeigt „Klasse hinzufügen“ (die anderen Klassen bleiben) – oder „Öffnen“, wenn die Klasse schon auf dem Gerät ist. Ungültiger Link mit bestehender Anmeldung: Hinweis und „Zurück zur App“ statt Anmeldeformular.
