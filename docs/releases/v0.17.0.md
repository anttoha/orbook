# ORBook v0.17.0

Seit v0.16.1 (14. November 2026). Teil 30 „Personalisierung + Animationen“.

## Neu
- **Start**: eigene Seite aus Blöcken (Jetzt, Woche, Tests, Aufgaben, Notizen …), „Anpassen“ mit Ziehen, Größen Klein / Breit / Groß, Block hinzufügen oder entfernen. Pro Klasse eine eigene Anordnung. Neue Nutzer starten mit Start; allen anderen wird er angeboten („Was ist neu“, Karte auf Start, Punkt in Darstellung).
- **Darstellung**: Design (Soft, Glas, Klar), Akzentfarbe, Glas-Hintergrund und „Glas-Effekt“ (Einfach für schwache Geräte), „Animationen“. Glas nutzt die Bibliothek `@zakisheriff/liquid-glass` 4.0.0.
- **Stundenplan** (Mehr → Darstellung): was in der Zelle steht, Fachfarbe, Woche und Tag.
- **Sync** nimmt `design`, `accent`, `glassBg`, `glassMode`, `motion`, `plan` und (pro Klasse) `startBlocks` mit. Alte App-Versionen überspringen die neuen Felder.

## Datenschutz
Text angepasst: neue Einstellungen liegen auf dem Gerät und im verschlüsselten Sync-Block. Server und Schnittstelle unverändert.
