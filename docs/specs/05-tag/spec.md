# 05 · Tag

**Статус:** готово для телефона. Раскладка ПК сверяется в части 12.
**Источники:** дизайн `05 Tag · Liste`, `06 Tag · Zeitleiste`, `07 Stunde · Details (Blatt)`, `08 Info zum Tag (Blatt)`, `docs/frontend/03-plan.md`, решения владельца от 2026-11-05 (`docs/PROGRESS.md`).

## Зачем
Ученик открывает один день и сразу видит: что идёт сейчас, что будет дальше, что отменили и заменили. Отсюда же открываются подробности урока и «Info zum Tag».

## Экраны
| Экран | Файлы дизайна | Что на нём |
|---|---|---|
| Список | `05 Tag · Liste` | шапка, переключатель, Info, карточка «Jetzt», уроки с паузами, заметки |
| Шкала времени | `06 Tag · Zeitleiste` | те же уроки блоками по времени, линия «сейчас», ближайшая Klausur |
| Урок | `07 Stunde · Details (Blatt)` | учитель, кабинет, курс, пояснение, кнопки Notiz и Teilen |
| Info zum Tag | `08 Info zum Tag (Blatt)` | текст школы и три момента жизни плана |

## Что куда нажимать
- Левая круглая стрелка → неделя этого дня.
- ‹ › или свайп влево и вправо → соседний учебный день. Выходные и каникулы пропускаются.
- (i) в шапке → «Info zum Tag». Плашка «Info zum Tag: …» → то же окно.
- Liste / Zeitleiste → вид дня (хранится в адресе `?ansicht=`).
- Урок → подробности. Долгое нажатие → меню урока.
- «+ Notiz» → новая заметка на день.

## Данные
| На экране | Откуда | Может быть пустым? |
|---|---|---|
| «Mittwoch · heute», «17. September» | дата из адреса, `meta.serverTime` | нет |
| «07:08» или «Mi 15:15» под датой | `changedLabel(day)`: `changedAt`, иначе `publishedAt` | да: место остаётся, строки нет |
| Плашка Info | `day.info` | да: плашки нет, кнопка (i) есть |
| Карточка «Jetzt» | `lessonState` | да: только сегодня и пока есть уроки |
| Урок | `lessons[]`: `subject`, `teacher`, `room`, `status`, `changes`, `info` | `subject`, `teacher`, `room` бывают `null` |
| Klausur внизу шкалы | `GET /api/exams`, `daysLeft` ≤ 7 | да: блока нет |
| Подробности плана | `changedAt`, `publishedAt`, `fetchedAt`, `stale` | да: «—» |

## Состояния
- Загрузка, ошибка, офлайн, день без плана: работают как раньше, вид сверяется в части 06.
- Пусто: все уроки скрыты выбором курсов → «Alle Kurse ausgeblendet» и кнопка показать.
- Нет учителя и кабинета: строка под предметом не рисуется. Нет только учителя: пишем «Raum 301» без точки впереди.
- `features.share = false`: кнопки «Teilen» в окнах нет.
- Урок исчез после обновления плана: окно урока закрывается.

## Чего здесь НЕТ
- «synchronisiert» в заметках: появится с синхронизацией в части 11. Пока «nur für dich» с замком.
- Настройка «Tag anzeigen als»: часть 09.
- Сверка раскладки ПК: часть 12. На ПК в этой части меняется только то, что общее с телефоном, и добавлены (i) и время изменения.

## Отличия от дизайна
- **Кнопка (i) и строка времени в шапке:** решение владельца, в макете их нет. Четвёртая круглая кнопка не помещается рядом с «17. September», поэтому (i) стоит маленьким значком рядом с «Mittwoch · heute». Шапка из-за новой строки выше макета на 14px.
- **Отменённый урок без учителя:** макет показывает «Sch», но API у отменённых уроков отдаёт `teacher: null` (`docs/API.md`). Показать нечего.
- **Заметки на шкале времени:** в макете 06 их нет, но без них заметки дня пропадали бы при смене вида. Оставлены.
- **Часовые линии шкалы:** в макете они сдвинуты относительно блоков на 7px (10:30 стоит не там, где должно быть по линиям). У нас всё считается по одной шкале, поэтому время на линиях точное.
- **Подробности плана в окне Info:** решение владельца, в макете их нет. Строки сделаны как в окне урока.

## Решения
- **Один вид карточки на телефоне и ПК.** Вариант со временем снаружи карточки был отступлением от макета, поэтому он убран. Меньше кода и нечему расходиться.
- **Высота блока на шкале меньше длительности урока:** блок рисуется в 1,2px на минуту, шкала идёт по 1,28px. Так получается зазор между уроками, как в макете.
- **Нет крестика в окне урока на телефоне,** как в макете: окно закрывается смахиванием и нажатием на фон. На ПК крестик есть.

## Слова
- **changedAt** — когда изменилось содержимое плана.
- **publishedAt** — когда школа выпустила файл плана.
- **fetchedAt** — когда наш сервер последний раз его проверял.
- **Zeitleiste** — вид дня, где высота блока зависит от длины урока.
