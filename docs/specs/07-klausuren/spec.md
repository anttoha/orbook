# 07 · Klausuren: просмотр

**Статус:** готово для телефона. Раскладка ПК сверяется в части 12.
**Источники:** дизайн `13 Klausuren`, `14 Klausur · Details (Blatt)`, `15 Klausuren · Filter (Blatt)`, `36 Klausuren · leer`, `docs/frontend/04-klausuren.md`, `docs/API.md` (раздел «Klausuren»).

## Зачем
Ученик должен за пять секунд увидеть, какие Klausuren и тесты впереди и сколько до них осталось, даже без сети.

## Экраны
| Экран | Файлы дизайна | Что на нём |
|---|---|---|
| Список | 13 | заголовок, чипы предметов, группы «Diese Woche / Nächste Woche / Später» |
| Детали | 14 | предмет, тема, сколько дней осталось, кнопки «Kalender» и «Teilen» |
| Фильтр | 15 | вид, предметы, период, «Vergangene anzeigen» |
| Пусто | 36 | «Keine Klausuren in Sicht» |

## Что куда нажимать
- Строка → окно деталей. Адрес `?sheet=klausur&id=12`, поэтому ссылку можно переслать, а «Назад» закрывает окно.
- Чип предмета включает или выключает предмет. «Alle» снимает выбор.
- Кнопка с воронкой в конце ряда чипов → окно фильтра.
- «3 anzeigen» применяет фильтр. Закрытие окна без этой кнопки ничего не меняет.
- «Zurücksetzen» сбрасывает выбор в окне, само окно остаётся открытым.
- «Kalender» скачивает `.ics`. «Teilen» открывает меню телефона, на ПК копирует текст.

## Данные
| На экране | Откуда | Может быть пустым? |
|---|---|---|
| Список | `GET /api/exams` | да: экран «leer» |
| Прошедшие | `GET /api/exams?past=true`, только после «Vergangene anzeigen» | да: «Nichts gefunden» |
| «Ab heute · 5 geplant» | число записей без фильтра | 0: только «Ab heute» |
| Подпись «Mathe · 1. Std» | `subject`, `lesson` | `lesson = null`: только предмет |
| Тема | `topic` | пустая: вместо неё название предмета |
| «in 2 Tagen» | `daysLeft`, `examWhen` | нет |
| Виды в фильтре | `meta.examTypes` | пока нет `meta`: только «Alle» |
| Предметы в фильтре | предметы выбранных курсов и Klausuren | `subject = null` пропускаем |
| Окно по ссылке | `GET /api/exams/{id}` | 404: «Diese Klausur gibt es nicht (mehr)» |
| Кнопка «Teilen» | `features.share` | выключено: кнопки нет |

## Состояния
- Загрузка: серые строки вместо списка.
- Офлайн и ответ 5xx: сохранённый список и плашка «Offline · Stand von …» или «Nicht erreichbar · Stand von …».
- Ошибка без сохранённого списка: «Klausuren konnten nicht geladen werden» и «Erneut versuchen».
- Пусто: экран 36.
- Фильтр ничего не нашёл: «Nichts gefunden» и «Filter zurücksetzen».
- Особые случаи: `daysLeft = 0` — «Heute», `1` — «Tag» в единственном числе, меньше нуля — «vor N Tagen». Прошедшие старше 14 дней показывают дату.

## Чего здесь НЕТ
- «+», «Bearbeiten» и «Editor-Code eingeben»: появятся в части 08 вместе с экранами, куда они ведут. Кнопка, которая никуда не ведёт, хуже её отсутствия.
- Раскладка ПК по макету (вкладки «Kommend / Vergangen», поиск, календарь): часть 12. На ПК пока работает тот же список, детали открываются панелью справа, фильтр окном.

## Отличия от дизайна
- **В видах фильтра есть «Abgabe».** В макете только Klausur и Test, но документация велит брать виды из `meta.examTypes`.
- **Подпись считает вид записи:** «Tage bis zum Test», «Tage bis zur Abgabe». Для вида, который завёл админ, — «bis zum Termin».
- **Период можно снять** повторным нажатием. В макете один вариант выбран всегда, но по умолчанию показывать надо весь список.
- **При «Vergangene anzeigen» период неактивен:** у прошедших его нет (`examsQuery`).
- **Кнопка фильтра подсвечивается, когда фильтр включён.** Вид и период в ряду чипов не видны, без подсветки список выглядел бы неполным без причины.
- **«Nichts gefunden»** в макете нет, без него фильтр давал бы пустой экран без объяснения.

## Решения
- **Фильтруем на устройстве, а не параметрами `type` и `to`.** Записей немного (до 500), поэтому число на кнопке «3 anzeigen» меняется сразу, без запроса на каждое нажатие, и фильтр работает без сети.
- **Сохранённый список пересчитывается.** Без сети `daysLeft` устаревает, поэтому вычитаем дни, прошедшие с момента сохранения, и убираем то, что уже прошло. Считаем от времени сохранения, а не от даты: на демо «сегодня» выдуманное. Свежий ответ сервера не трогаем.
- **Фильтр живёт в своём маленьком хранилище:** окно фильтра рисуется в `SheetHost`, вне страницы, а видеть его нужно обоим.
- **При заходе на страницу список запрашивается заново:** запись могли добавить одноклассники. Старые данные остаются на экране до ответа.

## Слова
- **Klausur** — большая письменная работа. **Test** — маленькая. **Abgabe** — срок сдачи.
- **ics** — файл события, его понимает любой календарь.
- **Editor-Code** — код от админа, дающий право вносить Klausuren (часть 08).
