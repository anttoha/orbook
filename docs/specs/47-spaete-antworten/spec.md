# 47 · Поздний ответ отменяет действие пользователя

**Статус:** готово (2026-11-25, демо + демо-APK)
**Источники:** строка 47 в `docs/specs/README.md` (ревью Codex, P1).

## Зачем
Ответ сервера, спрошенный до действия ученика («Abmelden», другой класс, новая настройка), не должен это действие отменять.

## Решение
| Где | Как |
|---|---|
| Noten (сайт) | номер сессии в `notenStore`: «Abmelden» (здесь или через Sync) — новая; ответ прошлой сессии выбрасывается. Старый APK, успевший сохранить логин, — ещё один `notenLogout` |
| Noten (Android) | `NotenSession`: проверка и запись под одной блокировкой; `NotenStore.logout()` начинает новую сессию; фон после выхода не сохраняет и не уведомляет |
| Смена класса, выход | «поколение» в `planStore`: другой класс, выход или 401 — новое; старые данные, ошибки и «загрузка закончилась» игнорируются |
| Офлайн-копия | после `cache.clearAll/clearClass` поздний ответ в кеш не пишется |
| Sync | `applyBlock` пишет Kurse, Darstellung, имя/цвет класса, Noten и цели только если они не старее своих; правки во время запроса уходят следующим проходом (`again`) |

## Проверки
Тесты с управляемой задержкой ответа: `notenStore.test.js`, `planStore.test.js`, `syncStore.test.js`, `NotenSessionTest.kt` (без исправления 11 тестов сайта падают).
