# 45 · «Abends schon morgen» в блоке «Heute»

**Статус:** готово (2026-11-25, демо)

## Зачем
Вечером уроки сегодняшнего дня уже не нужны — ученику важно, что завтра.

## Экраны
| Экран | Файлы дизайна | Что на нём |
|---|---|---|
| Шторка блока «Heute» (Start → «Anpassen») | существующая `BlockSheet` | новая строка-переключатель «Abends schon morgen» |
| Блок «Heute» на Start | pc-01 из `design/neu/30-personalisierung` | те же строки уроков, другой день и заголовок |

## Что куда нажимать
- Start → «Anpassen» → блок «Heute» → переключатель «Abends schon morgen» (по умолчанию выключен).
- Нажатие на блок открывает показанный день: сегодня — `/heute`, следующий — `/tag/<дата>`.

## Когда показывается следующий день
Настройка включена **и** одно из:
- сегодня выходной или schulfrei (`status = holiday`);
- план есть (`ok`), но «моих» уроков, которые не отменены, нет;
- последний не отменённый «мой» урок уже закончился (так же, как в виджете Android).

Следующий день — `nextSchoolDay` (без выходных и `meta.holidays`). Заголовок: «Morgen · 6 Stunden», если это не завтра — «Montag · 6 Stunden».

## Состояния
- Плана на сегодня нет (`not_published`/`unavailable` без Muster): остаёмся на сегодня — мы не знаем, кончились ли уроки.
- Следующий день ещё не загружен (в т. ч. офлайн в пятницу): остаёмся на сегодня, без вечной «загрузки».
- У следующего дня нет плана: «Plan fehlt noch» / «Nicht erreichbar» / «Schulfrei»; нет моих уроков: «Kein Unterricht».
- Muster — как раньше, с меткой. Урок без времени (10-й) в расчёт конца не входит.

Не нужно. Настройка — `opts.evening` блока «Heute», хранится и синхронизируется вместе с раскладкой Start. Datenschutz не меняется.
