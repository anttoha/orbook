# 08 · Klausuren: запись, Editor-Code

**Статус:** готово для телефона. Раскладка ПК сверяется в части 12.
**Источники:** дизайн `16 Klausur eintragen (Editor)`, `17 Klausur löschen (Dialog)`, `18 Editor-Code eingeben`, ПК `19 Editor-Code nötig (Fenster)`, `docs/frontend/04-klausuren.md`, `docs/frontend/08-zustaende.md` (тосты), `docs/API.md`.

## Зачем
Тот, у кого есть код от админа, вносит Klausur для всего класса. Остальные только читают.

## Экраны
| Экран | Адрес | Что на нём |
|---|---|---|
| Форма | `/testen/neu`, `/testen/12/bearbeiten` | вид, предмет, дата, урок, тема, «Speichern», «Löschen» |
| Удаление | диалог поверх формы | «Klausur löschen?» |
| Ввод кода | `/editor-code` | поле кода, «Freischalten»; если код уже есть — «Code entfernen» |
| Код посреди записи | окно поверх формы, `?sheet=editorcode` | то же поле: форма не теряется |

## Что куда нажимать
- «+» на экране Klausuren: есть право — форма, кода нет — ввод кода, потом сразу форма.
- «Bearbeiten» в окне Klausur: только если `exam.canEdit`.
- «Speichern» и «Löschen» — см. таблицу ниже.
- После удаления и сохранения тост с «Rückgängig».

## Данные
| На экране | Откуда | Может быть пустым? |
|---|---|---|
| «Editor · Code A» | `me.editor.label` | `null` при `examsWithoutCode`: «Klausur eintragen» |
| Вид | `meta.examTypes` | пока нет `meta`: Klausur, Test, Abgabe |
| Предметы | курсы ученика и `meta.subjects` | у правки добавляем предмет самой записи |
| Уроки | `meta.lessonTimes` | пока нет `meta`: 1–6 |
| «Code A · gültig bis 31.07.2027» | `me.editor` | `validUntil = null`: только метка |

## Ответы при сохранении
| Ответ | Что делаем |
|---|---|
| успех | закрыть форму, тост «Klausur gespeichert» и «Rückgängig» (6 с) |
| `409 duplicate` | диалог: «Ansehen» или «Trotzdem eintragen» (`force: true`) |
| `409 conflict` | диалог: текущая запись, «Meine Änderung trotzdem speichern» (версия из ответа) или «Verwerfen» |
| `422` | текст сервера под полем из `details.fields[0].field` |
| `403 editor_required`, `code_expired` | окно ввода кода поверх формы, форма остаётся |
| `403 forbidden` | тост с текстом сервера |
| `429` | тост `retryText` |
| нет сети | тост «Konnte nicht speichern — keine Verbindung» и «Nochmal», форма остаётся, очереди нет |

## Чего здесь НЕТ
- Раскладка ПК: окно формы, окно кода вместо страницы — часть 12. На ПК работает та же страница.
- Пункт «Editor-Code» в меню: часть 09. До неё страницу можно открыть через «+», а убрать код — только по адресу `/editor-code`.

## Отличия от дизайна
- **В диалоге удаления нет «Das lässt sich nicht rückgängig machen».** Это неправда: сервер хранит удалённое 30 дней, а документация требует тост с «Rückgängig».
- **Поле кода подсказывает `ORB-E-XXXX-XXXX`:** настоящая длина, в макете короче (так велит документация).
- **Заголовок правки «Klausur ändern»:** в макете есть только «Neue Klausur».
- **Формат даты задаёт устройство:** поле встроено в браузер, на немецком телефоне будет «19.09.2026», как в макете.
- **Состояние «код уже есть» на телефоне:** своего макета нет, текст взят из документации, вид — из общих кирпичиков.

## Решения
- **Код не хранится:** он живёт в поле до ответа сервера, потом стирается. Сервер сам помнит привязку к сессии.
- **Код посреди записи спрашиваем окном, а не страницей:** иначе ученик потеряет заполненную форму.
- **Старая дата при правке не проверяется:** сервер её принимает, а клиент иначе не дал бы исправить тему у прошедшей записи.
- **После записи обновляем и список, и открытые недели:** Klausur показывается и в плане.

## Слова
- **If-Match** — заголовок с версией записи: сервер откажет, если её уже изменили.
- **force** — «да, я знаю, что такая запись уже есть».
