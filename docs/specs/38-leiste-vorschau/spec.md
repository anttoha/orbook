# 38 · Untere Leiste: живое превью вместо дубля

**Статус:** готово на демо (2026-11-21)
**Источники:** `design/neu/38-leiste-vorschau/` (ок владельца 2026-11-21), часть 35 (`docs/specs/35-untere-leiste/spec.md`), код `src/pages/NavSettings.jsx`, `src/components/navbar/*`.

## Зачем
На телефоне на странице «Untere Leiste» панель была видна дважды: серое превью сверху и настоящая панель внизу. Превью убираем: правка сразу видна в настоящей панели, а изменённая вкладка коротко подсвечивается.

## Экраны
| Экран | Файлы дизайна | Что на нём |
|---|---|---|
| Телефон, обычное | `handy-01-live` | список сразу под заголовком, внизу настоящая панель (выбрана «Mehr») |
| Телефон, после правки | `handy-02-geaendert` | нажали «+» у Statistik — вкладка внизу появилась и коротко светится |
| Телефон, группа | `handy-03-gruppe` | нажали «Leistung» в панели — её меню, как на любом экране |
| ПК, «Handy» | `pc-01-handy` | справа от списка телефон (sticky) с нижней панелью |
| ПК, «Computer» | `pc-02-computer` | превью нет: только что добавленный пункт светится в боковом меню |

## Что куда нажимать
- Всё как в части 35 (минус, плюс, перетаскивание, карандаш группы, «Zurücksetzen», «Rückgängig»).
- После каждой правки на текущем устройстве коротко (~1,2 с) светятся вкладки, которые изменились:
  новая вкладка; группа, у которой поменялось содержимое; вкладка, сдвинутая на другое место; «Mehr», если что-то ушло в «Mehr».
- Телефон: светится настоящая нижняя панель. ПК + «Computer»: светится боковое меню (и «Mehr» внизу меню). ПК + «Handy»: светится панель в телефоне справа.
- Нажатие на группу в нижней панели — обычное меню группы (уже работает, ничего не меняем).

## Данные
| На экране | Откуда | Может быть пустым? |
|---|---|---|
| вкладки панели / меню | `userStore.nav` → `navOf`, `visibleNav` (как в части 35) | нет — пустое/битое → по умолчанию |
| что подсветить | `navChanges(before, after, features)` в `shared/utils/navLayout.js` → ключи; хранится в маленьком сторе `navFlashStore` (не сохраняется, не в Sync) | пусто — ничего не светится |

## Состояния
- Загрузка, офлайн, ошибка, пусто — нет: всё на устройстве.
- «Animationen: Aus» — подсветки нет (все анимации выключены, элемент подсветки по умолчанию невидим). «Weniger»/системное «уменьшить движение» — подсветка остаётся (это только прозрачность, без движения).
- Правка с другого устройства через Sync — без подсветки (светим только свои правки на этой странице).
- Ключ подсветки меняется при каждой правке — повторная правка той же вкладки снова её подсвечивает.

## Чего здесь НЕТ
- Подсветки в «Glas» на телефоне: там панель рисует библиотека (`GlassNav`), в свои кнопки мы не встраиваемся. Правка в «Glas» видна сразу, просто без кольца.
- Настоящего экрана Start внутри телефона на ПК (см. «Отличия»).
- Изменений в changelog для админки — их нет, часть для всех (запись в changelog — при «на прод»).

## Отличия от дизайна
- Телефон справа на ПК показывает не настоящий Start, а его упрощённые карточки-заглушки (`bg-card`) и панель. Настоящая страница Start внутри второй раз загрузила бы данные и подписки; для превью панели важна только панель.

## Слова
- **Превью** — картинка, как будет выглядеть панель.
- **Подсветка (flash)** — кольцо акцентного цвета и мягкий фон у вкладки, гаснут за ~1,2 с.
- **sticky** — блок остаётся на экране, пока прокручиваешь список рядом.
