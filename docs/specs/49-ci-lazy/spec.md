# 49 · CI и ленивая загрузка админки

**Статус:** готово (2026-11-26, демо)
**Источники:** строка 49 в `docs/specs/README.md` (ревью Codex).

## Решение
- `.github/workflows/ci.yml`, на каждый push и PR: `web` — `lint`, `test`, `build`; `android` — `testDemoDebugUnitTest` (там `NotenSessionTest` из части 47).
- `router.jsx`: все страницы `/admin/…` и «Klasse verwalten» — через `lazy`. `errorElement` остался; при прямом открытии `/admin` пока едет код — пустой фон.
