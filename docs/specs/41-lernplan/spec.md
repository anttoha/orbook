# 41 · Lernplan zum Test

**Статус:** готово (демо) (дизайн ок 2026-11-21, «сделать интереснее» — см. «Живость»)
**Источники:** `design/neu/41-lernplan/` (handy-01…08, pc-01/02), Soft 14 «Klausur · Details», часть 24 (описание теста `details`), часть 25 (Aufgaben, Sync), часть 30 (Start), `docs/API.md` → `GET /api/exams`.

## Зачем
Тест через неделю — а учить начинают накануне. Lernplan раскладывает темы теста по дням до него: каждый день одна задача в «Aufgaben», галочка, прогресс видно в тесте и на «Start».

## Что куда нажимать
- Шторка теста → «Lernplan erstellen» → `/testen/:id/lernplan`. Кнопки нет, если до теста не осталось ни одного дня для учёбы (тест сегодня или прошёл).
- «Wie viele Tage lernen?» — 1…7; цифры больше, чем доступных дней, бледные и не нажимаются. По умолчанию — 4 (или меньше, если дней меньше). Под цифрами — с какого по какой день.
- «Auch am Wochenende» — считать субботу и воскресенье (по умолчанию нет).
- «Themen» — строки из «Was lernen, was mitbringen» теста (галочкой можно убрать) + «Thema hinzufügen» (поле, Enter — добавить; своя тема удаляется крестиком).
- «So lernst du» — сразу пересчитывается. «Lernplan starten» → назад в шторку теста, тост «Lernplan gestartet».
- Шторка: кружок у дня = «erledigt» (то же, что галочка в Aufgaben). «Ändern» → тот же экран с «Speichern» и «Lernplan löschen» (окно с вопросом).
- Aufgaben / день: строка задачи плана открывает шторку теста; кружок — как у своих задач (с «Rückgängig»).
- Удалённый тест: карточка сверху в Aufgaben; «Lernplan löschen» — удалить задачи плана, «Behalten» — оставить их как обычные задачи плана без теста (карточка больше не появляется).

## Как раскладываются темы (`shared/utils/lernplan.js`, с тестами)
- Дни для учёбы: от сегодня до дня **перед** тестом, без Sa/So (если выключено). Берём **последние N** таких дней.
- Последний день — «Alles wiederholen» (если N ≥ 2). Остальные N−1 дней — темы по порядку; тем меньше, чем дней, — темы идут по кругу второй раз; тем больше — по несколько за день через « · ».
- Тем нет — каждый день «{Fach} lernen». N = 1 — один день «Alles wiederholen».
- Темы из описания: делим по строкам, «,» и «;», убираем пустые, пункты списков («-», «•», «1.»), дубликаты; не больше 10, каждая до 60 знаков.

## Данные
| На экране | Откуда | Может быть пустым? |
|---|---|---|
| Тест (предмет, тема, дата, урок) | `planStore.exams` (`GET /api/exams`), `useExam(id)` | `topic`, `lesson`, `subject`, `details` — `null` → «Fach lernen», без урока |
| Темы | `exam.details` | `null` → только свои темы |
| Задачи плана | `tasksStore.tasks` — своя задача с полем `plan` | — |

Задача плана = обычная своя задача (часть 25) + `plan: { exam: "12", cls: <id класса>, examDate, subject, label, title, topics: [...], weekend, review }`. Поэтому она **сама** едет через Sync (часть «Aufgaben»), старые версии приложения видят её как обычную свою задачу. Отдельного хранилища и бэкенда не нужно.
Изменить план = задачи пересоздаются (старые — «надгробки», как при удалении); сделанные дни с той же темой остаются сделанными.

## Состояния
- Загрузка: шторка теста как раньше (Skeleton); экран плана без теста в списке — запрос `GET /api/exams/{id}` (`useExam`), пока грузится — Skeleton.
- Офлайн: план работает целиком (всё на устройстве). Проверка «перенесли/удалили» идёт **только** при свежем списке (`examsState.status === "ready"`), не из кэша.
- Ошибка: тест не найден по ссылке — «Diesen Test gibt es nicht (mehr).» (как в шторке).
- Пусто: нет описания — тем нет, «So lernst du» с «{Fach} lernen».
- Перенесли (`exam.date` ≠ `plan.examDate`): несделанные задачи переезжают на последние дни перед новой датой, сделанные остаются, тост «Test verschoben · Lernplan angepasst». Нет дней (тест сегодня) — задачи не трогаем.
- Удалили: тест не в свежем списке, `examDate ≥ сегодня`, план этого класса → карточка в Aufgaben.
- Другой класс (29d): план привязан к `cls`; в чужом классе его не проверяем и в шторке не показываем.

## Живость (просьба владельца «сделать интереснее», 2026-11-21)
- Кружок дня в шторке — та же «пружинка», что в Aufgaben; полоска прогресса плавно растёт.
- Сегодняшний день в карточке подсвечен (tint-фон), «Heute» акцентом.
- Последний день отмечен — карточка становится «Alles gelernt!» (значок-искра, «Viel Erfolg beim Test!»), тост «Alles gelernt – viel Erfolg!». Без конфетти: правило владельца 13.11 «без ИИ-слоп анимаций» (движение короткое и тихое), всё уважает «Animationen».
- Тост при галочке дня плана: «Erledigt · noch {n}» вместо просто «Erledigt».

## Слова
- **Lernplan** — список задач «что учить в какой день» до теста.
- **надгробок (tombstone)** — удалённая задача остаётся записью `deleted: true`, чтобы удаление дошло до других устройств через Sync.
- **`plan.examDate`** — дата теста, когда план строили; не совпадает с `exam.date` — значит тест перенесли.
