# 42 · Notenziel + Verlauf

**Статус:** в работе (дизайн ок 2026-11-22)
**Источники:** `design/neu/42-notenziel/` (handy-01…05, pc-01), часть 36b (`docs/specs/36b-noten-screen/spec.md`, `src/components/noten/*`, `shared/utils/noten.js`), Sync — `shared/utils/syncPayload.js`.

## Зачем
Ученик ставит себе цель по предмету («Ziel 2,0») и сразу видит, что нужно на следующей работе и реально ли это. График показывает, как Schnitt менялся за полугодие.

## Экраны
| Экран | Файлы дизайна | Что на нём |
|---|---|---|
| Noten (обзор) | `handy-01-noten` | значок «Ziel 2,0» цветом статуса у предмета; плитка «Schnitt» с мини-графиком, «Ziel 2,0 · 14 Noten», шеврон |
| Предмет | `handy-02-fach`, `handy-05-fach-ohne-ziel` | карточка Schnitt цвета предмета с графиком и пунктиром цели; карточка цели (или «Ziel setzen»); оценки; «Nächster Test» |
| Шторка «Mein Ziel» | `handy-03-ziel` | бывший Notenrechner: Ziel ±, «Nächste Note zählt ×1/×2», «Du brauchst … oder besser» + статус, «Speichern», «Ziel entfernen» |
| Schnitt | `handy-04-schnitt` | общий график с общей целью, строка «Mein Ziel», «Ziele in Fächern» со статусом |
| ПК | `pc-01-noten` | справа у предмета — та же карточка с графиком (все даты, если их ≤ 8) и карточка цели; шторка — окном |

## Что куда нажимать
- Плитка «Schnitt» → `/noten/schnitt?hj=1` (на ПК — в правой колонке вместо предмета).
- Карточка цели или «Ziel setzen» → шторка «Mein Ziel» (на ПК — окно). «Speichern» — сохранить и закрыть; «Ziel entfernen» (только если цель есть) — убрать и закрыть; крестик — закрыть без изменений.
- «Mein Ziel» на экране Schnitt → та же шторка, но только строка «Ziel» (без веса и результата).
- Строка в «Ziele in Fächern» → предмет.
- Вкладка «Zeugnis» — без целей и графиков (как раньше).

## Данные
| На экране | Откуда | Может быть пустым? |
|---|---|---|
| Оценки, даты, вес | `notenStore.data` (ответ InfoPoint, часть 36b) | `date`, `value`, `weight` — бывают `null`: без даты/числа оценка в график не идёт, вес `null` = ×1 |
| Цели | новый `notenZielStore` (localStorage `orbook.notenziel`) | нет цели — «Ziel setzen» / «Kein Ziel» |
| Цели на другом устройстве | Sync-блок, новое поле `ziele: { value, updatedAt }` | старый блок без поля — у нас ничего не меняется |

Хранение: `ziele = { "1:ma": { ziel: 2.0, k: 2 }, "1:*": { ziel: 2.0 } }` — ключ «полугодие:код предмета», `*` — общий Schnitt. `k` — вес следующей оценки, который выбрал ученик.
Sync: `ziele` едет вместе с частью «Noten» (переключатель в Sync тот же), побеждает более новое изменение (`newerSetting`). Сервер видит только зашифрованный блок.
«Abmelden» цели **не стирает** — это не данные школы, при новом входе они снова пригодятся.

## Расчёты (`shared/utils/notenZiel.js` + тест)
- **Что нужно** — `neededGrade` из 36b (не меняем).
- **Статус** (по нужной оценке `need` и текущему Schnitt `avg`):
  - `sure` (хватит любой) или `need ≥ avg` → **erreichbar** (зелёный, `bg-ok-tint text-ok`);
  - `avg − need ≤ 0,7` → **knapp** (`bg-sand text-ink`);
  - сильнее или `impossible` → **schwer** (`bg-danger-tint text-danger`);
  - `avg` = `null` (нет оценок с числом) → статуса нет.
- **Ход Schnitt**: оценки полугодия с `date` и `value`, по дням по возрастанию; точка дня = Schnitt всех оценок до этого дня включительно. Общий ход: на каждый день — среднее Schnitt предметов, у которых к этому дню уже есть оценка.
- **Шкала**: 1 сверху; низ = max(3, округлённое вверх худшее значение и цель), не больше 6.

## Состояния
- Загрузка / офлайн / ошибка InfoPoint — как в 36b (график строится из кеша на устройстве).
- Меньше 2 точек — вместо графика «Verlauf ab 2 Noten».
- Нет цели — «Ziel setzen»; на плитке «Schnitt» и в карточке справа — без «Ziel …»; на экране Schnitt «Ziele in Fächern» не показываем, если целей нет.
- Предмет без оценок с числом — карточка цели без строки «Nächste Note …».

## Слова
- **Ziel** — какой Schnitt ученик хочет в предмете (или в среднем).
- **Verlauf** — график, как менялся Schnitt по датам оценок.
- **erreichbar / knapp / schwer** — насколько реальна цель одной следующей оценкой.
- **k** — сколько «весит» следующая оценка (×1 или ×2).

## Datenschutz
