# 48 · Офлайн после первого визита и лимиты Karteikarten

**Статус:** готово (2026-11-26, демо)
**Источники:** строка 48 в `docs/specs/README.md` (ревью Codex, P2), лимиты — spec 43.

## Зачем
ORBook должен открываться без сети уже после одного визита; карточка не должна пропадать молча.

## Решение
- `public/sw.js`, `install`: кладёт в кэш `/` и все файлы из него (сборка, шрифты из CSS, иконки). `/` — последней.
- `karten.js`: `cardsLimitError`, `deckLimitError` (500 карточек в стопке, 60 стопок; удалённые не считаются) — для «Karte hinzufügen», списка, нового стапеля и «Stapel übernehmen». Список длиннее 500 больше не обрезается.
- При отказе — ошибка (`ui/ErrorText` или под полем), введённый текст остаётся. «Fertig» при полной стопке: первый раз ошибка, второй — закрыть.

## Проверки
`kartenStore.test.js`. Чистый профиль: один визит → сервер выключен → страница открывается (со старым `sw.js` — нет).
