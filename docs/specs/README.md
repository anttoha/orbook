# Части приложения (specs)

Как работаем:
- `/orb-auto` — Claude делает части по порядку сам и останавливается только когда нужен пользователь.
- `/orb <часть>` — одна часть целиком (дизайн при необходимости → spec → код → проверки → демо).
- Пользователь: смотрит дизайн новых экранов («ок дизайн»), проверяет демо, говорит «на прод».
- Когда чат стал большим — новый чат и снова `/orb-auto` (прогресс в `docs/PROGRESS.md`).
