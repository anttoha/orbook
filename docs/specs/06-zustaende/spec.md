# 06 · Состояния и офлайн

**Статус:** готово для телефона. Раскладка ПК сверяется в части 12.
**Источники:** дизайн `29 Woche · lädt`, `30 Tag · lädt`, `31 Plan nicht erreichbar`, `32 Offline · letzter Stand`, `33 Neuer Plan da (Hinweis)`, `34 Tag · frei`, `35 Tag · Plan fehlt noch`, `38 Meldungen (Toasts)`, `docs/frontend/08-zustaende.md`, `docs/API.md`.

## Зачем
Школьный сервер падает, в автобусе пропадает сеть, план меняется прямо во время урока. Ученик должен понимать, что происходит, и не терять последний план.

## Экраны
| Состояние | Когда | Что на экране |
|---|---|---|
| Загрузка | данных ещё нет | шапка настоящая, остальное серые заглушки |
| Plan kommt gerade nicht an | ответ 5xx или `day.status = unavailable` | экран с кнопками «Erneut versuchen» и «Letzten Stand zeigen · 07:12» |
| Offline | нет сети, есть сохранённый план | плашка «Offline · Stand von heute 07:12», под ней обычный план |
| Neuer Plan | `lastChangeAt` новее того, что ученик уже видел | плашка «Neuer Plan · Morgen: 4. Std Geschichte → Vertretung», кнопка «Ansehen» |
| Frei | `day.status = holiday` | «Heute ist frei», «Schulfrei» или «Wochenende», ссылка на следующий учебный день |
| Plan fehlt noch | `day.status = not_published` | объяснение, «Jetzt prüfen», серые уроки «vorläufig» |

## Что куда нажимать
- «Erneut versuchen», «Neu laden» → снова запросить неделю.
- «Letzten Stand zeigen» → сохранённый план с плашкой «Nicht erreichbar · Stand von …». Держится, пока школа снова не ответит.
- «Ansehen» → обновить неделю, больше не напоминать об этом изменении.
- «Jetzt prüfen» → `POST /api/plan/refresh` и тост с результатом.

## Данные
| На экране | Откуда | Может быть пустым? |
|---|---|---|
| «Stand von heute 07:12» | время сохранения ответа на устройстве | да: только «Offline» |
| Что изменилось | `planChanges`: прошлый и свежий `GET /api/week`, первая замена среди курсов ученика | да: «Neuer Plan da» |
| Какое изменение уже видели | `localStorage`, `orbook.seenChange` | да: при первом запуске запоминаем, плашки нет |
| Klausur у дня без плана | `day.exams` | да: плашки нет |

## Отличия от дизайна
- **Устаревший план не закрывается экраном ошибки.** `08-zustaende.md` называет `plan/status.stale` причиной экрана 31, а `API.md` пишет для `stale` только «показывайте Stand». План при этом есть и читается, прятать его незачем. Давность показывает красная строка «aktualisiert …» и окно «Info zum Tag». Экран появляется только на настоящие ошибки 5xx.
- **Заметки на дне без плана скрыты, если их нет,** как в макетах 34 и 35. Если заметка есть, она видна.
- **Текст свободного дня общий:** «Laut Plan kein Unterricht.» Названия праздника в данных нет.
- **«ORBook schaut regelmäßig nach»** вместо «alle 5 Minuten»: так требует документация, на каникулах сервер смотрит раз в час.
- **Кнопка «⋮» вместо календаря** в шапке недели: решение части 04.
- **Плашка «Nicht erreichbar»** после «Letzten Stand zeigen»: в макете этого шага нет, а без неё было бы не видно, что план старый.

## Решения
- **Свежий план не подменяет экран сам.** Неделя для сравнения запрашивается отдельно, таблица меняется только по «Ansehen»: иначе уроки двигались бы, пока ученик их читает.
- **В плашке только курсы ученика.** Замена в чужом курсе не повод писать про неё.
- **«Plan neu laden» считается просмотром:** ученик сам обновил план, плашка уже не нужна.
- **Один тост за раз,** новый заменяет старый, как требует документация.

## Слова
- **Скелет** — серые заглушки на месте будущих данных, чтобы экран не прыгал.
- **lastChangeAt** — когда план изменился в последний раз.
- **stale** — последняя успешная проверка плана была давно.
