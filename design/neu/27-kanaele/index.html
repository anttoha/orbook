Часть 27 · Kanäle + Für morgen

Kanäle

ORBook сам пишет в Telegram-канал класса: новый план с тем, что изменилось, и после уроков — тесты и домашки на завтра. Основа — Soft 45 «Admin · Einstellungen» и строки Soft 26. Всё нарисовано токенами Soft; в конце — старые экраны для сравнения.

1 · Admin → Kanäle: что и когда шлёт ORBook

Новый раздел админки (на ПК — пункт меню, на телефоне — из Einstellungen и «Übersicht → Schnell»). Сверху — подключён ли Telegram-канал и «Test senden». «Was wird gesendet»: новый план сразу (только изменения), «Für morgen» — тесты и домашки через N минут после последнего урока, новый тест (выключен). N меняется в шторке «Für morgen · wann?» (15/30/45/60/90, по умолчанию 30). Ниже — пример сообщения, WhatsApp и что уже отправлено.

2 · Подключить Telegram

Пока не подключено — большая карточка «Telegram verbinden». В шторке три шага: создать бота у @BotFather и вставить его токен; добавить бота админом в канал или группу класса; ORBook сам находит канал — остаётся нажать «Mit „9b Plan“ verbinden». Код в канал писать не надо.

3 · WhatsApp, ошибки, загрузка

WhatsApp не даёт программам писать в группы (официальный API — только переписка компании с одним человеком, у каналов WhatsApp API нет). Поэтому «Nachricht teilen»: готовый текст, кнопка открывает WhatsApp, группу выбираешь сам. Если бота убрали из канала — красная карточка и «Neu verbinden». «Trennen» спрашивает подтверждение.

Для сравнения: старые экраны Soft

Какие экраны менялись.

Сообщения (примеры)

  • Neuer Plan «Neuer Plan für Donnerstag, 13.11. · 3 Änderungen: 2. Std Mathe – fällt aus; 4. Std Geschichte – Vertretung Roth, B12; 6. Std Sport – in Halle 2 · Alles ansehen: orbook.orbitium.net». Ничего не изменилось — ничего не шлём. Несколько изменений за минуты — одно сообщение.
  • Für morgen «Für morgen, Freitag 14.11. · Test: Mathe – Klassenarbeit · Aufgaben: Deutsch …, Englisch … · Erste Stunde: 07:30 Deutsch, Raum 102». Если на завтра нет ни тестов, ни домашек — только «Erste Stunde». Перед выходными — про понедельник, в пятницу.
  • Neuer Test eingetragen «Neu: Englisch – Test am Do 20.11.» (по умолчанию выключено).

Что изменится на сервере

  • Telegram-бот класса. Токен бота хранится на сервере зашифрованным (как ключи Mitteilungen), назад не показывается. Сервер сам спрашивает Telegram (без вебхука, nginx не трогаем) и узнаёт канал, куда бота добавили.
  • Отправка. «Neuer Plan» — по тому же событию, что Live и Mitteilungen; «Für morgen» — такт раз в минуту: конец последнего урока + N минут. Одно и то же дважды не уходит, история — 30 дней (как «Zuletzt gesendet»).
  • Без новых библиотек. Telegram Bot API — обычные HTTPS-запросы через уже установленный httpx.

Что нужно решить

  1. Ок дизайн? Что поменять.
  2. Бот. Каждый класс создаёт своего бота у @BotFather (2 минуты, токен вставляется в админке, в чат его слать не надо) — ок? Или один общий бот ORBook, который ты создашь сам?
  3. Приватность. В канале — предметы, Kürzel учителей, кабинеты, тесты и домашки; имён учеников нет. Канал лучше закрытый (по приглашению). Ок так?
  4. Что слать. Neuer Plan и Für morgen включены, Neuer Test выключен; N = 30 минут. Ок?
  5. WhatsApp. Автоматически нельзя — только «Nachricht teilen» в админке. Нужна ли такая кнопка ещё и ученикам (например, в «Info zum Tag»)?
